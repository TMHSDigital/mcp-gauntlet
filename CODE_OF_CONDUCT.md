# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). The full text at that link applies to every project space: issues, pull requests, discussions, and any other place where the project is represented.

## In short

- Be respectful. Disagree about the work, not about the person.
- Give and take feedback in good faith.
- No harassment, no personal attacks, no publishing someone's private information.

## One rule specific to this project

mcp-gauntlet is a tool for testing agents you own or have written permission to test. Do not use project spaces to plan, request, or share results from attaching it to someone else's agent or service without their consent.

## Reporting

To report behaviour that breaks this code, contact the maintainers privately by opening a report at
<https://github.com/TMHSDigital/mcp-gauntlet/security/advisories/new> and starting the title with "Conduct:". Only the maintainers can read it. You can also use GitHub's own "Report content" option on any comment.

Maintainers will review every report, keep the reporter's identity confidential, and decide on a response following the enforcement guidelines in the Contributor Covenant.
